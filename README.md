# Certified GRC Engineer - Practitioner (CGE-P) Labs

My implementations of the GRC Engineering Club CGE-P labs. Each lab produces Terraform that
enforces a compliance floor, captures machine-readable evidence, and builds toward the chain
from Terraform to JSON evidence to Rego policy to an OSCAL component definition.

Design decisions and the chain-of-custody argument are in [WRITEUP.md](WRITEUP.md).
